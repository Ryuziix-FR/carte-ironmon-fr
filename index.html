        Carte IronMON FR

        • Clic sur un dresseur ou un objet : le cocher (battu / ramassé). Re-clic pour décocher.
        • Clic droit (ou appui long sur téléphone) : le marquer d'une étoile, pour s'en souvenir.
        • Passages : clique sur un carré de couleur pour sauter à l'autre bout.
        • Recherche : un lieu (« Route 32 », « Rosalia »), un dresseur (« Albert »), « CT », « caché », « arène ».
        • Tracker : si la carte est ouverte sur le PC du stream, via le serveur du tracker (http://localhost:8080/carte-ironmon/), elle montre où tu es pendant la run.
        • Pour OBS : ajoute ?obs=1 à l'adresse (mini-carte qui suit ta position).
